**The Excuse That Almost Works** — one excuse texted to the boss to skip work during GTA 6 launch week. `main.ts` (Node 22, no network, no dependencies) writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when run locally).

The joke is in the boring specificity: a broken boiler, an engineer who can't come till Thursday, a freezing flat, hands too cold to type. Nothing about games, nothing dramatic — just a small domestic disaster with its own airtight logic, the kind of excuse a tired manager almost believes because it is too dull to invent. The line is 97 characters and 17 words, inside the 140-character / 20-word gate.

## Run it

```sh
node main.ts
```

Then read `output/entry.txt` (or `/output/entry.txt` in the grading sandbox).
